### Ресурсы, к которым не удалось получить доступ (не «пусто», а «закрыто»)

Это важно отличать от негативов — там результат может быть:

- **Familio.org** — поиск персон **закрыт авторизацией**. API отвечает дословно: `{"type":"simple_error","message":"Требуется авторизация","code":2}` (HTTP 401). Публичная страница `/persons` игнорирует фильтры и отдаёт только «недавно добавленных». Внешний индексный поиск по familio.org наших имён не находит, но **это не доказательство отсутствия** — нужно зайти под аккаунтом и повторить поиск вручную.
- **pamyat-naroda.ru** — HTTP 401, страница «Проверка безопасности» (антибот). Это **главная потеря**: именно там у карточек есть поле «Место рождения», по которому можно было бы отсеять/подтвердить четырёх кандидатов из п. 2.1. Нужно проверить вручную из браузера.
- **gwar.mil.ru** (Первая мировая — по Николаю Ефремовичу Орлову) — TLS-ошибка (российский корневой УЦ) / HTTP 503. Не проверен.
- **geni.com** — HTTP 403 на поиск. Внешний поиск по geni.com наших имён не дал ничего.
- **MyHeritage / Ancestry / FamilySearch Tree** — поиск персон только под авторизацией; публично проиндексированных страниц с нашими именами нет.

### Полезное побочное: FamilySearch, Самара 1918

Коллекция **«Russia, Samara, Civil Registers», ID 2040542** — https://www.familysearch.org/search/collection/2040542 — охватывает **1918–1922, записи ЗАГС города Самары** (рождения, браки, разводы, смерти; в записях о рождении есть «имена родителей», иногда «девичья фамилия матери»). Источник — ГА Самарской области. **Коллекция без индекса, только образы** (дословно с вики-страницы: «This collection does not have a searchable index. Only images are available»). Это прямой путь к девичьей фамилии Евдокии, если семейная версия о рождении в Самаре 14.03.1918 верна: нужно листать записи о рождении за март 1918 г. вручную.

### Что я сознательно НЕ сделал и почему

- Не выдал ни одного из четырёх «Орловых Владимиров Николаевичей 1918» за нашего — в их карточках нет места рождения, а комбинация ФИО+год слишком массовая.
- Не связал «Евдокию Прокофьевну Девину» (Астрахань) с нашей Евдокией — совпадает только имя-отчество.
- Не стал утверждать, что Орлов Геннадий Николаевич из Ашхабада — родственник; общее отчество и город это только повод для письма, не находка.
- Не проверил pamyat-naroda.ru, gwar.mil.ru, Familio, Geni, MyHeritage, FamilySearch Tree и содержимое групп ОК/ВК — все они закрыты авторизацией или антиботом. Это **не негативы**, это непроверенные направления, и именно там (особенно на pamyat-naroda.ru — поле «Место рождения») лежит следующий шаг.
