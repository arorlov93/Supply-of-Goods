# МАСШТАБИРОВАНИЕ ДО ~3000 ЦЕЛЕЙ + COMPLIANT FOLLOW-UP (email → звонок → SMS)
Архитектура «упакованной» outreach-машины ISP по 3 рынкам. Обновлено 14.08.2026.

## 0. ЧЕСТНО ПРО SMS (читать первым — это про штрафы)
🚨 **Холодные SMS запрещены (TCPA + правила 2025).** Нельзя автоматически слать SMS людям,
которые не дали номер и согласие. Штраф $500–1500 за сообщение, иски пачками. Поэтому:
- **COLD-касание = email + контактные формы. SMS в холодную — НИКОГДА.**
- **SMS/звонок разрешён как FOLLOW-UP ТОЛЬКО «тёплым»:** тем, кто ответил, оставил номер, или
  явно согласился на контакт (например, в ответе на письмо или через форму «call/text me»).
- Для бизнес-SMS в США нужна регистрация **10DLC** (Brand + Campaign) у оператора
  (Twilio/Telnyx) — иначе несущие блокируют. Это ~день на регистрацию + небольшая плата.
- **Звонки:** ручной звонок на бизнес-номер (из пермита) допустим как первое касание — это делает
  ЧЕЛОВЕК (агент готовит список+скрипт). Автозвонки/robocalls — запрещены (TCPA).

**Вывод по follow-up-лестнице (compliant):**
1. Email #1 (cold, Brevo) → 2. Email #2 через 5–7 дней (cold) → 3. Контактная форма (если нет email)
→ 4. **Звонок человеком** по телефону из базы → 5. **SMS — только если контакт стал тёплым**
(ответил / дал номер / согласился), через 10DLC-номер. Агент готовит текст, отправка тёплым — ок.

## 1. КАК НАБРАТЬ ~3000 ЦЕЛЕЙ (по 3 рынкам)
Источник — публичные пермиты (кто строит/владеет сейчас) + отраслевые базы. Оценка охвата:
- **Miami-Dade (FL):** ArcGIS permits, commercial building, 90 дней, $150k+ → ~700–1000 GC/owners.
  Расширить: +Broward (data), +Palm Beach → ещё ~500–800.
- **Los Angeles (CA):** data.lacity.org building permits (Socrata) → ~800–1200 (для site services+supply).
- **San Francisco (CA):** data.sfgov.org permits (i98e-djp9) → ~300–500.
- **Property managers / facility management** (для cleaning/janitorial) — отдельный слой по всем 3.
- **Отраслевые** (уже идут): BidNet, PlanHub, SAM — тендерный поток, не в счётчик 3000.
Итого реалистично **2,500–3,500 уникальных целей**. Дедуп по домену/компании обязателен.

⚠️ 3000 целей ≠ 3000 писем в день. Deliverability-лимиты: держим **25–40 email/день на домен**
(прогрев нового домена — меньше). 3000 целей = ~3–4 месяца ровной капельной рассылки на одном
домене, или быстрее при **нескольких прогретых доменах-отправителях** (ispgroupfl.com и т.п.,
каждый со своим DKIM/DMARC, каждый на своём лимите). Мгновенно «залить 3000» = спам-бан. Так нельзя.

## 2. ДВИЖОК (что строим поверх текущего)
Уже есть: Brevo email + DKIM/DMARC, contact-form submitter, Miami-Dade permits, CRM (recipients.csv),
Brevo suppression/bounce, ежедневная рутина. Достраиваем:
- **Мульти-рынок лид-загрузчик:** скрипты под LA (Socrata) и SF (Socrata) + Broward/PB — единый
  формат recipients (market, trade_fit, source, contact, status).
- **Мульти-домен ротация** отправителей (для объёма без потери репутации) — по мере роста.
- **Follow-up движок:** авто email #2 (T+5–7д), очередь «на звонок» (нет email/капча), очередь
  «SMS тёплым» (после ответа/согласия) через 10DLC-провайдер.
- **Сегментация по рынку/услуге:** FL-отделка / CA-site-services / supply — свои шаблоны и правила
  (лицензионные, из licensing-roadmap).
- **Дашборд метрик:** отправлено/доставлено/открыто/ответы/квоты по рынку и трейду.

## 3. COMPLIANCE-РАМКА (жёстко)
- CAN-SPAM (email): адрес, opt-out, честный From — уже встроено.
- TCPA (SMS/звонок): cold SMS нет; SMS только warm/opt-in; 10DLC; DNC-уважение; звонки — человек.
- Лицензии по рынку (licensing-roadmap): FL отделка ок; CA отделка — supply/partner; CA cleaning —
  janitorial DLSE-регистрация если свои работники + city business reg (LA BTRC / SF).
- Suppression: opt-out/bounce/конкуренты/DNC — единый список, проверка перед любым касанием.
