## Почему поток SAM ≠ поток предложений
Ежедневный SAM даёт сотни opps, но 90%+ — либо brand-name мебель, либо out-of-state материалы, либо
set-aside, которых у нас нет. Реальные наши gov-цели: **FL state/local self-perform услуги** (BidNet/HigherGov)
+ **суб к FL-primes** (PlanHub/BC). По ним и готовим пакеты.

## РЕШЕНИЕ ДЛЯ ПОЛЬЗОВАТЕЛЯ (разблокировка мебели/материалов)
Чтобы зайти в gov-мебель/материалы (крупные деньги), нужен один из шагов:
1. **Furniture dealer/reseller** — получить авторизацию HON/Global/Steelcase или партнёрство с дилером → тогда
   мебельные set-aside (их много, SB) становятся реальными.
2. **Materials supplier** — договор с FL-поставщиком (aggregate/plaster/tile) → supply-тендеры с ценой.
Без этого gov-фокус = FL self-perform услуги + субподряд. Оба варианта могу проработать по твоему выбору.
