# ОТЧЁТ PHASE 1 — АУДИТ АМЕРИКАНСКИХ PROCUREMENT-ПЛОЩАДОК ДЛЯ ISP GROUP

**Система:** Tender Intelligence & Bid Operations System
**Дата:** 10 августа 2026
**Статус:** PHASE 1–7 завершены. TOP 10 финализирован (см. раздел 11). **SAM.gov уже зарегистрирован** (подтверждено пользователем). Регистрационные чек-листы созданы в `/tender-system/registrations/`.

## 1. Методология

Исследовано **30 площадок и каналов** по официальным источникам (2024–2026): сайты площадок, документация регистрации, прайс-страницы, официальные FAQ, живые solicitations. Непроверяемые данные помечены как UNKNOWN — возможности площадок не придумывались.

Товарные направления ISP Group:
- **A — Construction Materials:** щебень, гранит, заполнители, гравий, песок, road base
- **B — Construction Equipment:** краны-манипуляторы, погрузчики, экскаваторы, вилочные погрузчики
- **C — Restaurant / Hospitality Furniture:** мебель для ресторанов, отелей, учреждений

Ключевой фильтр: возможность участвовать как **SUPPLIER / VENDOR / DISTRIBUTOR** (поставка товаров), а не строительный подрядчик.

### Scoring model площадок (0–100)

| Фактор | Вес |
|---|---|
| Relevance to ISP products | 25 |
| Количество релевантных opportunities | 20 |
| Качество заказчиков | 15 |
| Возможность поставки товаров (supplier-роль) | 15 |
| Стоимость регистрации | 5 |
| Простота регистрации | 5 |
| Автоматические alerts | 5 |
| Electronic submission | 5 |
| Качество данных / API | 5 |

Категории: **90–100 = PRIORITY A**, **75–89 = PRIORITY B**, **60–74 = PRIORITY C**, **<60 = DO NOT PRIORITIZE**.

## 4. TOP 5 PLATFORMS FOR IMMEDIATE REGISTRATION

1. **SAM.gov** — бесплатно; обязательное условие для любых федеральных продаж (UEI + CAGE); открывает API для автоматизации; живые тендеры на щебень уже в 2026.
2. **BidNet Direct** — free-tier сразу; группы FL/TX/CA/NY/NJ; лучший подтверждённый поток товарных тендеров (A+B).
3. **MyFloridaMarketPlace (VIP) + VBS** — бесплатно; приоритетный штат №1; UNSPSC-alerts; FDOT как якорный покупатель.
4. **Texas ESBD + CMBL ($70/год)** — приоритетный штат №2; NIGP-alerts по классам 750 (материалы), 755/760 (техника), 420/425 (мебель).
5. **TIPS** — бесплатно; ближайшие ежемесячные циклы RFP по Furniture и Heavy Duty Infrastructure Equipment — самый быстрый путь к кооперативному контракту.

## 5. TOP 5 PLATFORMS TO MONITOR WITHOUT REGISTRATION

1. **GSA eBuy / GSA MAS** — регистрация невозможна без Schedule-контракта; мониторим категорию мебели (~$900M/год) и готовим отдельное решение о подаче на MAS (TAA-происхождение мебели — критическое требование).
2. **SBA SUBNet** — открытый просмотр без аккаунта; периодическая проверка subcontracting-лидов (поставка материалов primes на федеральных стройках).
3. **USASpending.gov** — бесплатный API без аккаунта; award intelligence: кто, где и почём покупает по нашим NAICS/PSC.
4. **OMNIA Partners** — нет vendor-регистрации в принципе; мониторим страницу Current Solicitations на предмет мебельного RFP Region 4 ESC.
5. **E&I Cooperative** — мониторим календарь RFP по мебели для вузов; вход разумен позже (или как дилер производителя с действующим контрактом).

## 6. TOP 5 PLATFORMS TO REJECT (на текущем этапе)

1. **GovWin IQ** — $6–30k+/год; функциональность перекрывается связкой BidNet + S2G + BidPrime-trial за <1% этой цены. Вернуться при масштабировании.
2. **Bid Express** — система торгов для лицензированных DOT-подрядчиков, а не поставщиков; прямых supply-тендеров почти нет. Позже возможен как лид-ген primes ($60/мес).
3. **Public Purchase** — ядро в Юте/Mountain West; в FL/TX/CA/NY/NJ покрытие слабое.
4. **Thomasnet (платный тир)** — сыпучие материалы геопривязаны, ROI платного продвижения сомнителен. Бесплатный листинг — опционально, без приоритета.
5. **ConstructConnect / Dodge** — полезен для коммерческих лидов по материалам, но платный (~$1k+/мес пакеты) — отложить до запуска активных продаж направления A.

## 7. Почему каждая площадка подходит или не подходит ISP Group

### PRIORITY A

**BidNet Direct (94).** Единственный агрегатор, где напрямую подтверждены живые товарные тендеры по нашим категориям: «Aggregates Statewide» (штат Нью-Йорк OGS), «Road Base and Construction Materials» (Waller County, TX), «Washed Crushed Stone» (Danbury, CT), Compact Track Loader (Texas Parks & Wildlife), вилочные погрузчики (Louisiana, Pittsburgh Transit). Выделенные purchasing groups по всем 5 целевым штатам, NIGP-alerts, электронная подача. Free-tier для старта, платные пакеты дешёвые. Минус: нет API — потребуется работа через alerts/выгрузки.

**SAM.gov (91).** Обязательная точка входа в федеральный рынок и одновременно лучший прямой источник: подтверждены действующие RFQ на щебень/заполнители для Fort Riley, Glacier NP, Modoc NF (NAICS 212321) — регулярные, повторяющиеся закупки баз, парков и лесничеств. Бесплатно, включая UEI и CAGE. Get Opportunities API — фундамент нашего Discovery Engine. Минусы: конкуренция, преобладание small business set-asides (нужно проверить размер ISP по SBA size standard — для 212321/423810/337127 это преимущество), Buy American на поставки.

**Texas SmartBuy / ESBD (90).** Редкий случай: один борд собирает штат + университеты + города + округа. Порог публикации $25k+. CMBL за $70/год даёт адресные NIGP-уведомления. Важно: TxDOT переводит дорожные материалы в prequalified low-bid контракты — для объёмов по щебню в TX параллельно нужны TxDOT Material Producer List и prequalification.

**MyFloridaMarketPlace / VBS (90).** Приоритетный штат. FDOT официально закупает через VBS «aggregates… heavy equipment… furniture» — прямое совпадение со всеми тремя направлениями. Регистрация VIP бесплатна, UNSPSC-alerts. Минус: 1% transaction fee со всех платежей штата (закладывать в цену).

### PRIORITY B

**TIPS (85).** Самый «пробиваемый» кооператив: solicitations каждый месяц, множественные awards на категорию, действующие контракты «Furniture, Furnishings and Services» и «Heavy Duty Infrastructure Equipment». 2% fee только с фактических продаж. Подходит: B+C сразу, A — через trades-контракты.

**DemandStar (82).** Исторический лидер Флориды (штаб-квартира Plantation, FL; St. Lucie, Sunrise, Deltona и др.). FL-подписка $100–1499/год закрывает наш штат №1 на муниципальном уровне. Вне FL — слабее, поэтому это дополнение, а не базис.

**BuyBoard (79).** Техасские школы и муниципалитеты: контракт 682 (стройтехника, вкл. погрузчики) и 667 (мебель, вкл. столовые/аудитории) — прямое попадание в B и C. Вход бесплатный, 2% с PO. Минус: циклы RFP ~раз в 3 года — важно не пропустить пересолиситацию.

**Periscope S2G / SOVRA (78).** Двухслойный: бесплатные прямые регистрации на штатных ePro-порталах (BuySpeed/BidBuy-типа) + платный агрегатор (~$109–274/мес, цены неофициальные). Стратегия: бесплатный слой сейчас, платный — только после trial и сравнения с BidNet (один владелец — KKR/SOVRA, высокое пересечение).

**NJSTART (78).** Бесплатный современный портал NJ с NIGP-alerts и полной электронной подачей. Победа в штатном контракте открывает co-op продажи местным. Обязательное условие до award — NJ Business Registration Certificate (BRC), оформляется и для out-of-state компаний.

**Sourcewell (76).** Флагманская категория Heavy Construction Equipment — главный кооперативный канал техники в США. Но awards получают ОЕМ (Caterpillar, Komatsu, Volvo CE) — реалистичный путь ISP: дилер/дистрибьютор под контрактом производителя или узкая подкатегория. Регистрация на портале бесплатна — ставим alerts и ждём цикл.

**Unison Marketplace (75).** Бесплатный федеральный reverse-auction маркетплейс (150k+ продавцов, 94% awards малому бизнесу). Хорош для commodity-закупок техники и мебели. Минусы: ценовая борьба, ~3% fee зашивается в цену.

**PlanetBids (75).** Ключ к муниципальной Калифорнии (~1900 агентств: Anaheim, Riverside, LA-регион). Но каждое агентство — отдельный портал и отдельная регистрация: берём пакетно 20–40 целевых агентств CA. Вне CA бесполезен.

**NYS Contract Reporter (75).** Официальный бесплатный борд всех закупок штата NY от $50k (~900 живых объявлений). Только реклама — подача через каждое агентство отдельно. Регистрация бесплатна, alerts по категориям.

**Bonfire / Euna (75).** Бесплатная регистрация + Supplier Network Pro за $50/год с рекомендациями от 3000+ агентств. Уклон в RFP/услуги, но школьные и окружные товарные тендеры идут. Также это движок подачи для PANYNJ. Дешёвый второй эшелон.

**BidPrime (75).** «Радар» на 120k+ источников с real-time keyword alerts. Стратегия: бесплатный 30-дневный trial, чтобы измерить фактический месячный поток по нашим категориям в 5 штатах, и только потом решать о подписке.

### PRIORITY C

**GSA eBuy (74).** Для мебели — премиальный канал (~$900M/год категория Furniture & Furnishings), но вход только через GSA MAS-контракт: месяцы подготовки, TAA-происхождение товара, 0.75% IFF. Отдельный стратегический проект для направления C, не первая волна.

**NYC PASSPort (74).** Единый портал закупок Нью-Йорка: бесплатно, полная электронная подача. Наиболее реален для мебели (школы, агентства). Вторая волна.

**GovWin IQ (74).** Максимальное покрытие SLED + pre-RFP разведка, но $6–30k+/год — на нашем этапе не окупается.

**Cal eProcure (73).** Только агентства штата CA (местные — на PlanetBids и др.); aggregates у Caltrans уходят в стройподряды. Бесплатно — регистрируемся во второй волне, ожидания умеренные. Без CA SB-сертификации (недоступна out-of-state) конкурируем без 5%-преференции.

**OpenGov Procurement (73).** Бесплатно, один логин на все агентства, силён в городах/округах CA. Вторая волна — нулевая стоимость, средний поток.

**ConstructConnect (69).** Лучший источник коммерческих (негосударственных) лидов для направления A — все стройпроекты региона на стадии торгов. Платный (quote-based, реально $1k+/мес) — отложить.

**DLA DIBBS (66).** Бесплатно, полная онлайн-подача, авто-awards мелких RFQ. Но объём в наших категориях невысок: FSC 5610 встречается, техника идёт через prime vendor программы (HEPP, MRO), мебель почти отсутствует. Третья волна, после SAM.

**USASpending.gov (65 — intel-слой, не тендерная площадка).** Бесплатный API без регистрации: полная история федеральных наград по NAICS 212321/423810/337127 — кто покупает, где, почём, кто конкуренты. Обязательный компонент Award Intelligence модуля.

**E&I (63).** Мебель для вузов — точное попадание в C, но контракты у Steelcase/Global и др. производителей. Реалистичный вход — дилерство. Мониторинг календаря RFP.

**PANYNJ (63).** Гигантский бюджет одного заказчика, но прямые товарные закупки по нашим категориям эпизодичны. Бесплатная регистрация оправдана при работе в NY/NJ метро — вторая волна.

**OMNIA Partners (61).** Крупнейший кооператив, но модель «лид-агентства» означает конкуренцию с национальными производителями за 3–5-летние мастер-контракты. Только мониторинг мебельных пересолиситаций Region 4.

### DO NOT PRIORITIZE

**Public Purchase (58)** — покрытие сосредоточено в Юте/Mountain West, целевые штаты слабые. **Thomasnet (53)** — B2B-дискавери промышленных товаров; для геопривязанных сыпучих материалов платное продвижение не окупится (бесплатный листинг — опционально). **SBA SUBNet (52)** — полезен только как бесплатный мониторинг subcontracting-лидов, без регистрации и автоматизации. **Bid Express (47)** — канал ставок лицензированных дорожных подрядчиков, ISP как поставщик там не участвует; ценность только как источник лидов «кому продать щебень» ($60/мес) — позже.

## 8. Ключевые требования и риски перед регистрацией

1. **SAM.gov:** нужны юридические данные ISP Group (legal entity, EIN, адрес, банк для EFT), выпускается бесплатный UEI и CAGE; ежегодное продление. Регистрация занимает до 2–4 недель. Остерегаться платных «посредников» — официальная регистрация только на sam.gov и бесплатна.
2. **Small business status:** проверить размер ISP по SBA size standards для NAICS 212321 / 423810 / 337127 — большинство федеральных тендеров на щебень идут как Total Small Business Set-Aside.
3. **Buy American / TAA:** для федеральных поставок критично происхождение товара (особенно мебели). Требует ревизии цепочки поставок ISP до подачи первого федерального bid.
4. **Флорида:** 1% transaction fee; **Техас:** CMBL $70/год + отдельная TxDOT prequalification для дорожных материалов; **NJ:** BRC до award; **CA:** нет преференций для out-of-state.
5. **Кооперативы (TIPS/BuyBoard/Sourcewell):** вход бесплатный, но циклы RFP периодические — пропуск цикла = ожидание 1–4 года. Регистрация «на alerts» нужна сразу, даже если бид позже.
6. Нигде на state/local-площадках SAM/UEI не требуется — достаточно данных компании, W-9/TIN и товарных кодов (NIGP/UNSPSC).

## 10. Следующие шаги (после подтверждения)

1. Утверждение пользователем TOP 5 для регистрации (PHASE 6–8).
2. Сбор регистрационных данных ISP Group (Registration Checklist): legal entity, EIN, адрес, контакты, банковские реквизиты для SAM EFT, описание компании, товарные коды.
3. Пошаговая регистрация с фиксацией статусов в `/tender-system/registrations/` (без хранения паролей — только .env/secret storage).

5. Построение Tender Discovery Engine: SAM.gov API + USASpending API + email-alerts парсинг (PHASE 10+).
