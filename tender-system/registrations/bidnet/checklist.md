# BidNet Direct — чек-лист регистрации

- Registration URL: https://www.bidnetdirect.com/registration
- Стоимость: Free-tier (ручной поиск). Платные statewide-пакеты (авто-alerts по NIGP) — цены показываются на шаге выбора пакета; решение о платном пакете принимает пользователь.
- Prerequisites: только данные компании + NIGP-коды. SAM/UEI не нужны.

## Шаги
1. [ ] Создать аккаунт (email тендерного ящика, контактное лицо, компания, адрес, телефон).
2. [ ] Выбрать purchasing groups: Florida, Texas, California, Empire State (NY), New Jersey.
3. [ ] Указать NIGP-коды: 750 (road/highway materials), 020/545/760 (equipment), 420/425 (furniture).
4. [ ] Free-tier активировать сразу; платный пакет — показать пользователю цены и дождаться решения.
5. [ ] Настроить email-alerts (при платном пакете) на тендерный ящик.
6. [ ] Зафиксировать login URL и выбранные коды в status.md; пароль — только в менеджере паролей пользователя.

## Требуется от пользователя
- Подтверждение покупки платного пакета (если free-tier окажется недостаточным после 1–2 недель наблюдения).
