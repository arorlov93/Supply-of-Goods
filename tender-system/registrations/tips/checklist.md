# TIPS (The Interlocal Purchasing System) — чек-лист

- Registration URL: https://tips.ionwave.net (eBid System, Ionwave) ; инфо: https://www.tips-usa.com/vendors/become
- Стоимость: бесплатно; ~2% admin fee только с фактических продаж по контракту.
- Prerequisites: данные компании; EDGAR-формы при подаче предложения (юридическое подтверждение — пользователь).

## Шаги
1. [ ] Зарегистрировать supplier-аккаунт в Ionwave eBid.
2. [ ] Выбрать commodities: Furniture/Furnishings; Heavy Equipment/Infrastructure Equipment; Trades/Materials.
3. [ ] Включить email-уведомления (solicitations публикуются в первый четверг месяца).
4. [ ] Отслеживать ближайшие циклы: «Furniture, Furnishings and Services» и «Heavy Duty Infrastructure Equipment» — подготовка предложения = отдельный проект с участием пользователя (EDGAR, подписи).
5. [ ] status.md: дата, выбранные категории.

## Требуется от пользователя
- Подписание vendor agreement / EDGAR-сертификаций при подаче на конкретный RFP (не при регистрации).
