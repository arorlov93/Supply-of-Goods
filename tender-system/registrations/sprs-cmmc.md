# SPRS / CMMC — что это и что нужно ISP

## Что такое SPRS

**SPRS (Supplier Performance Risk System)** — база данных Минобороны США (DoD), где хранится
оценка кибербезопасности поставщика. Для большинства DoD-контрактов (включая простые поставки
мебели/стеллажей) в RFQ включаются клаузулы **DFARS 252.204-7019/7020**: у оферента на момент
award должна быть в SPRS **действующая Basic Self-Assessment оценка по NIST SP 800-171**
(самооценка, не аудит). CMMC Level 1 — это самодекларация о 15 базовых практиках защиты
Federal Contract Information (FCI).

Без записи в SPRS DoD-контракт формально присудить нельзя, если клаузула в solicitation.
Гражданские агентства (USDA, GSA, VA — частично) этого не требуют → тендеры Kerrville и
Wyndmoor НЕ затронуты.

## Как получить (бесплатно, ~1–2 часа, делает пользователь)

1. Зарегистрироваться в **PIEE** (piee.eb.mil) — аккаунт вендора, роль «SPRS Cyber Vendor User».
2. Пройти опросник NIST SP 800-171 Basic Self-Assessment по методологии DoD
   (110 требований; для компании, где FCI обрабатывается на 1–2 ноутбуках с базовой
   гигиеной — паролей/обновлений/шифрования — реалистичный честный скор считается по формуле,
   максимум 110).
3. Внести скор и дату в SPRS (привязка к UEI/CAGE 217F4).
4. CMMC Level 1 self-assessment — аналогично, самодекларация ежегодно.

⚠️ Скор должен быть честным: ложная самооценка = риск по False Claims Act. Для старта
достаточно скромного скора с планом действий (POA&M) — сам факт записи открывает DoD-квоты.
