# Cal eProcure (CSCR) — чек-лист

- Registration URL: https://caleprocure.ca.gov → Supplier Registration (FI$Cal bidder ID)
- Стоимость: бесплатно.
- Prerequisites: legal name, TIN/EIN, UNSPSC-коды. Out-of-state допускаются. CA SB/DVBE-преференции (5%) недоступны out-of-state — конкурируем без них.

## Шаги
1. [ ] Зарегистрировать bidder-аккаунт в FI$Cal/Cal eProcure.
2. [ ] Выбрать UNSPSC-коды: сегменты 11/30, 22, 56.
3. [ ] Включить «Receive Notification = Yes» для email-alerts по кодам.
4. [ ] Помнить: только агентства штата; местные CA-заказчики — через PlanetBids/OpenGov (вторая волна: пакет 20–40 целевых агентств).
5. [ ] status.md: дата, коды.

## Требуется от пользователя
- Ничего на этапе регистрации.
