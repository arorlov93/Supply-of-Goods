# NJSTART — чек-лист

- Registration URL: https://www.njstart.gov (Vendor registration, портал /bso)
- Стоимость: бесплатно.
- Prerequisites для регистрации: EIN, данные компании. **Перед первым award** (не для регистрации): NJ Business Registration Certificate (BRC) через NJ-REG — для out-of-state компаний без tax nexus подаётся бумажная форма.

## Шаги
1. [ ] Зарегистрировать vendor-аккаунт (EIN, компания, контакты).
2. [ ] Выбрать NIGP-коды: 750, 755/760, 020, 420/425.
3. [ ] Включить автоматические bid-уведомления по кодам.
4. [ ] Отметить в CRM задачу: оформить NJ BRC при первом выходе в финал по NJ-тендеру.
5. [ ] status.md: дата, коды.
