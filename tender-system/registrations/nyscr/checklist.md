# NYS Contract Reporter — чек-лист

- Registration URL: https://www.nyscr.ny.gov (бесплатная регистрация)
- Стоимость: бесплатно (все сервисы NYSCR бесплатны).
- Prerequisites: только данные компании. Для реальных контрактов со штатом NY позже: NYS vendor file (SFS) + VendRep questionnaire — фиксируем как задачу при первом биде.

## Шаги
1. [ ] Зарегистрировать аккаунт.
2. [ ] Выбрать категории NYSCR (собственная таксономия — подобрать эквиваленты: aggregates/road materials, heavy equipment, furniture).
3. [ ] Включить email-alerts по категориям.
4. [ ] Помнить: NYSCR — только объявления; подача идёт каждому агентству по инструкции конкретного объявления.
5. [ ] status.md: дата, категории.

## Требуется от пользователя
- Ничего на этапе регистрации.
