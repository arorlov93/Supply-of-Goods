# MyFloridaMarketPlace (VIP) + Vendor Bid System — чек-лист

- Registration URL: https://vendor.myfloridamarketplace.com (Vendor Information Portal)
- Bid search (без логина): VBS — vendor.myfloridamarketplace.com/search/bids
- Стоимость: регистрация бесплатна. **1% transaction fee** с платежей штата (Rule 60A-1.031) — закладывать в цены.
- Prerequisites: **Florida Substitute W-9** (подаётся в FL Dept. of Financial Services — flvendor.myfloridacfo.com), TIN/EIN. Out-of-state вендоры допускаются.

## Шаги
1. [ ] Подать FL Substitute W-9 (нужен подписант со стороны пользователя).
2. [ ] Регистрация в VIP: данные компании, адрес, контакты.
3. [ ] Выбрать UNSPSC-коды: сегменты 11/30 (материалы), 22 (техника), 56 (мебель).
4. [ ] Включить solicitation notifications по выбранным кодам.
5. [ ] Проверить доступ в MFMP Sourcing (электронная подача).
6. [ ] status.md: зафиксировать дату, коды, login URL.

## Требуется от пользователя
- Подписание FL Substitute W-9 (юридическое действие — только пользователь).
