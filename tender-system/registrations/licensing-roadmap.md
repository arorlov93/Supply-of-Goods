# ЛИЦЕНЗИИ ISP GROUP — что нужно, чтобы продавать услуги напрямую
Штукатурка / стяжка / внутренняя отделка · рынки: Miami-Dade (FL) и California (SF/LA)
Обновлено 14.08.2026 · источники: Miami-Dade CTQB, CSLB CA (ссылки внизу).

## ГЛАВНОЕ (быстрый путь для новой компании)
В ОБОИХ штатах лицензию держит не обязательно владелец. Компанию можно **«квалифицировать»
через специалиста, у которого уже есть лицензия и стаж** — это «Qualifying Agent» (FL) /
«Qualifying Individual» RME/RMO (CA). То есть у Александра лично 4 года опыта иметь не нужно —
можно нанять/взять в партнёры квалификатора, и бизнес получает право работать под лицензией.
Это самый реалистичный старт. Ниже — оба варианта (свой экзамен vs квалификатор).

---

# 1. FLORIDA / MIAMI-DADE — штукатурка, стяжка, отделка
Эти трейды НЕ лицензируются штатом FL (DBPR лицензирует GC/building), а регулируются на уровне
округа. Нужен **Miami-Dade Certificate of Competency (CTQB)** по нужному трейду:
- **Plastering / Stucco** → «Lathing & Plastering Contractor» (штукатурка, lath, metal studs).
- Флоринг/tile, drywall — отдельные specialty-категории CTQB (по каждой свой Certificate).
- (Broward и Palm Beach — свои county-сертификаты; начинаем с Miami-Dade.)

**Что нужно для Certificate of Competency:**
1. **Опыт:** документально подтверждённый (обычно несколько лет) — письма от работодателей с
   датами и описанием работ + **W-2 за период**. Точное число лет по Lathing&Plastering —
   уточнить в CTQB (варьируется по трейду).
2. **Экзамен:** open-book, проходной **70%+**, проводится раз в месяц. Книги по категории — по
   списку CTQB.
3. **Две заявки:** личный Certificate of Competency + бизнес-Certificate (на ISP GROUP LLC).
4. **Страховка:** GL (у нас есть, $1M) + **Workers' Comp** (или exemption) — обязательны.
5. Финансовая ответственность / регистрация бизнеса, сборы (уточнить актуальные суммы в CTQB).

**Путь-квалификатор (быстрее):** взять человека с действующим Miami-Dade Lathing&Plastering
Certificate как Qualifying Agent компании → ISP получает бизнес-сертификат без личного экзамена
Александра. Ему платим зарплату/долю; он несёт квалификацию.

**Сроки/стоимость (ориентир):** экзамен+заявки — недели-месяцы, если сдавать самому (собрать
опыт+W2, дождаться месячного экзамена). Через квалификатора — быстрее (дни-недели на оформление).
Сборы округа обычно несколько сотен $.

# 2. CALIFORNIA (SF + LA) — CSLB, обязательна для работ ≥ $500
🚨 Без CSLB-лицензии выполнять/контрактовать отделку в CA нельзя. Нужна **C-35 (Lathing &
Plastering)** для штукатурки; для другой отделки — свои: C-15 (Flooring), C-54 (Tile),
C-9 (Drywall), B (General Building).

**Требования CSLB (2026):**
1. **Опыт:** **4 года** journeyman/supervisory по трейду за последние 10 лет (до 3 лет можно
   заместить профильным образованием; self-employed опыт принимается).
2. **Два экзамена:** Law & Business + trade-экзамен C-35 (Planning/Estimating, Lath, Plaster/
   Stucco, Repairs, Safety).
3. **Fingerprints (Live Scan)** → DOJ + FBI.
4. **Contractor Bond $25,000** (обязателен) + рабочая страховка; Workers' Comp при наёмных.
5. **Сбор заявки $450** (+ выдача лицензии, экзаменационные).
6. Возраст 18+, знания по B&P Code §7068.

**Путь-квалификатор (RME/RMO):** нанять/партнёрить с человеком, у которого есть C-35 (или B) и
4 года опыта, как Responsible Managing Employee/Officer → ISP получает CSLB-лицензию через его
квалификацию (личный опыт Александра не требуется). RME должен реально участвовать в управлении.

**Сроки/стоимость (ориентир):** самому — **месяцы** (набор/подтверждение 4 лет опыта, 2 экзамена,
fingerprints, бонд). Через RME/RMO — быстрее, но найти надёжного квалификатора и оформить бонд.
Полный бюджет: заявка $450 + бонд $25k (обычно покупается страховкой ~$250–800/год) + экзамен-
подготовка + возможная зарплата/доля квалификатору.

# 3. РЕКОМЕНДАЦИЯ ПО ПРИОРИТЕТУ
1. **Сначала Miami-Dade (FL)** — это наш основной рынок и активная рассылка. Проверить точные
   требования Lathing&Plastering в CTQB; параллельно искать квалификатора с этим сертификатом.
   Быстрее и дешевле, чем CA. Открывает legal self-perform по штукатурке/стяжке в Miami-Dade.
2. **Workers' Comp / exemption** — оформить в любом случае (нужно и для CTQB, и для prequal у GC,
   и для CA). FL exemption на управляющего члена ~$50, онлайн.
3. **California — только через RME/RMO-квалификатора ИЛИ пока держим режим supply/partner.**
   Самим набирать 4 года и сдавать 2 экзамена — долго; для входа в SF/LA реалистичнее найти
   licensed CA-партнёра (JV) или C-35 RME. До этого в CA продаём ТОЛЬКО материалы (как в промте).

# 4. ЧТО ДЕЛАТЬ СЕЙЧАС (чек-лист)
- [ ] FL: позвонить/зайти в Miami-Dade CTQB — уточнить по Lathing&Plastering: годы опыта, список
      книг экзамена, актуальные сборы, дата ближайшего экзамена.
- [ ] Оформить Workers' Comp exemption (myfloridacfo.com) — разблокирует prequal-анкеты (NEI и др.).
- [ ] Решить путь FL: сдавать самим (собрать опыт+W2) ИЛИ искать квалификатора (Qualifying Agent).
- [ ] CA: подтвердить режим — supply/partner (сейчас) или искать C-35 RME/партнёра (для self-perform).
- [ ] Заложить бюджет: FL сертификат (несколько сотен $) + WC; CA (если идём) — бонд $25k + $450 + RME.
