# DemandStar — чек-лист

- Registration URL: https://network.demandstar.com (Supplier registration)
- Стоимость: free-tier (1 агентство, $5/скачивание пакета). Рекомендация: **Florida State subscription** ($100–1499/год в зависимости от плотности агентств — точную цену покажет портал) после 1–2 недель на free-tier.
- Prerequisites: только данные компании; SAM/UEI не нужны.

## Шаги
1. [ ] Создать supplier-аккаунт (тендерный email).
2. [ ] Free-tier: выбрать 1 стартовое агентство FL (предложение: округ с активными закупками aggregates — St. Lucie County или Hillsborough).
3. [ ] Выбрать commodity-коды (материалы/техника/мебель).
4. [ ] Через 1–2 недели — показать пользователю статистику потока и цену FL-подписки для решения.
5. [ ] status.md: дата, агентства, коды.

## Требуется от пользователя
- Решение о платной FL-подписке после оценки free-tier.
