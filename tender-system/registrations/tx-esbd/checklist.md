# Texas ESBD + CMBL — чек-лист

- ESBD (просмотр, бесплатно, без логина): https://www.txsmartbuy.gov/esbd
- CMBL регистрация: https://comptroller.texas.gov/purchasing/vendor/cmbl/ — **$70/год**
- Prerequisites: EIN; Texas Identification Number (TIN присваивается Comptroller при setup для платежей); out-of-state допускаются.

## Шаги
1. [ ] Оформить CMBL-членство ($70/год — оплата картой; платёж подтверждает пользователь).
2. [ ] Указать NIGP class/item: 750 (road/highway building materials — sand, gravel, crushed stone), 755/760 (дорожная и стройтехника), 020 (agricultural/construction equipment), 420/425 (мебель).
3. [ ] Указать обслуживаемые районы TX (highway districts) — определить с пользователем логистический охват.
4. [ ] Проверить получение авто-уведомлений ESBD (>$25k по нашим кодам).
5. [ ] Отдельный трек по щебню (НЕ регистрация, стратегич. задача): TxDOT Material Producer List + prequalification — оценить после первых тендеров.

## Требуется от пользователя
- Оплата $70/год; выбор геоохвата внутри Техаса.
