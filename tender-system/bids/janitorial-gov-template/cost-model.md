# COST MODEL — JANITORIAL GOV BID (переиспользуемый шаблон)
Под FL state/local janitorial RFP (Miami-Dade JLS, Tampa, Early Learning Coalition, cities, school districts).
Self-perform (FL — лицензия не нужна). Наценка: cost + 20% profit + 7% contingency + overhead/insurance.

## КАК СЧИТАТЬ МЕСЯЧНУЮ ЦЕНУ (recurring janitorial)
Ключевой драйвер = **производительность уборки** (SF/час на клинера) × ставка × частота + расходники + supervision.

### Базовые ставки (FL рынок, 2026)
| Компонент | Значение |
|---|---|
| Загруженная ставка клинера (wage + payroll tax + WC + GL) | ~$26–30 /час |
| Производительность (general office, light clean) | 3,000–3,500 SF/час |
| Производительность (medical/detailed) | 2,000–2,500 SF/час |
| Расходники (мешки, химия, бумага если наша) | ~$0.01–0.02 /SF·мес |
| Supervision + QC (аллокация) | +8–10% к труду |

### Формула
Месячный труд = (SF ÷ производительность) × визитов/мес × загруж.ставка
Цена/мес = (труд + расходники + supervision) × 1.20 (profit) × 1.07 (contingency)

### Пример — офис 20,000 SF, 5×/нед (≈21.7 визитов/мес), general clean
- Труд/визит = 20,000 ÷ 3,200 SF/час = 6.25 ч × $28 = $175/визит
- Месяц труд = $175 × 21.7 = $3,798 + supervision 9% = $4,140 + расходники (20k×$0.015)=$300 → $4,440
- × 1.20 × 1.07 = **≈ $5,700/мес** → **$68,400/год** (≈ $0.24/SF·мес — верх вилки для 5×/нед detailed)
- Для входа/конкуренции опустить к **$0.15–0.18/SF·мес** = $3,000–3,600/мес, если скоуп легче/частота ниже.

## ЧТО ПОДТВЕРДИТЬ ИЗ КОНКРЕТНОГО RFP
- Prevailing/living wage (город Miami-Dade / Tampa могут требовать living wage — поднимет ставку клинера).
- Частота, площадь, часы (день/ночь), расходники (наши/их), day porter, спец-работы.
- Страховка (обычно GL $1M — есть), performance bond (для мелких janitorial редко), background checks (часто).
- Сертификация (Miami-Dade SBE / Tampa SLBE) — гейт для set-aside.
