# COST MODEL — FSW 26-02 Job Order Painting &/or Pressure Cleaning (JOC)
Buyer: Florida SouthWestern State College (FSW) · через BidNet Direct · Sol. 26-02 · addendum опубликован 17.08.
Тип: **Job Order Contract (JOC)** — победитель получает пул работ; цена = набор **unit-prices**, применяемых к
конкретным work orders. Self-perform (FL, лицензия на покраску по HB 1383 не требуется).

## Модель наценки (как во всех наших пакетах)
Firm unit price = market cost (labor+material+equip) + 20% net profit + 7% contingency + overhead/insurance,
округление до «чуть ниже середины рынка» для входа новой компании.

## Допущения / что подтвердить из официального пакета (BidNet)
- Точная **форма bid** и перечень CLIN/позиций FSW может отличаться — эти unit-prices переносятся в их форму.
- Проверить в addendum: prevailing wage (гос. проект штата FL обычно без Davis-Bacon, но подтвердить),
  требования по страховке (обычно GL $1M — у нас есть), bid bond (для JOC часто не требуется — подтвердить).
- Кампусы FSW: Lee (Fort Myers), Charlotte (Punta Gorda), Collier (Naples), Hendry/Glades — mobilization
  учитывает разъезд; при работах в Collier/Charlotte добавить $150 к mobilization.
- Материалы: Sherwin-Williams / PPG commercial (contractor pricing), submittals на утверждение FSW.
