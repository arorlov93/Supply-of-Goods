# Сайт ispgroupgc.com

Одна страница, `index.html`, без зависимостей кроме шрифтов Google Fonts.
Открывается как есть, сборка не нужна.

## Что заполнить перед публикацией

В разделе Contact стоят два placeholder'а, помеченных красным:

- `[ to be filled in ]` — телефон
- `[ street, city, FL, ZIP ]` — юридический адрес

Адрес нужен не только для доверия: **коммерческая рассылка из США обязана
содержать физический почтовый адрес отправителя по CAN-SPAM.** Тот же адрес
надо поставить в подпись почты.

## Как выложить на домен

У домена сейчас есть MX на Google Workspace, но нет ни одной A- или
CNAME-записи, то есть сайта нет вообще. Любой из вариантов ниже это чинит.

**Cloudflare Pages** (бесплатно, быстрее всего):
1. Залить папку `site/` в репозиторий или перетащить через Direct Upload.
2. Custom domains → добавить `ispgroupgc.com` и `www.ispgroupgc.com`.
3. Cloudflare выдаст записи. **MX не трогать**, иначе развалится почта.

**Netlify** — то же самое, drag-and-drop папки плюс Domain management.

**Google Sites** — если не хочется новых сервисов: Workspace уже оплачен,
домен подключается в настройках публикации. Минус: вёрстку придётся
пересобирать в их редакторе, этот HTML туда не загрузить.

## Проверка после публикации

- `https://ispgroupgc.com` и `https://www.ispgroupgc.com` оба отвечают 200
- почта продолжает ходить (отправить себе письмо)
- в DNS остались MX на `aspmx.l.google.com` и TXT с SPF
