# Документы компании

## W-9

`W-9 ISP GROUP LLC.pdf` собирается командой:

```
curl -o /tmp/fw9.pdf https://www.irs.gov/pub/irs-pdf/fw9.pdf
python3.13 tools/w9.py /tmp/fw9.pdf
```

Бланк берётся прямо у налоговой, редакция **March 2024**. Значения
впечатываются в страницу, поля формы убираются, поэтому файл выглядит
одинаково в любой программе и значения в нём не правятся.

**Поля Signature и Date остаются пустыми.** Подписывает человек, см.
`CLAUDE.md`, раздел 4. Отдавать контрагенту только подписанный файл.

### Что в нём стоит и почему

| Строка | Значение | Откуда |
|---|---|---|
| 1, Name | `ISP GROUP LLC` | карточка SAM, та же пара имя плюс EIN прошла сверку с налоговой 30.07.2026 |
| 2, Business name | пусто | торгового имени, отличного от строки 1, нет |
| 3a | LLC, классификация `S` | `registrations/REGISTRATION-DATA.md` |
| 5, 6, адрес | `16395 Biscayne Blvd Apt 818`, `Aventura, FL 33160-5743` | карточка SAM |
| Part I, EIN | наш | `registrations/REGISTRATION-DATA.md` |

### Что было не так в прежней версии

Прежний файл, редакция October 2018, в строке 1 нёс имя **ISP Infrastructure
Partners LLC** при нашем EIN. Налоговая числит этот номер за **ISP GROUP
LLC**. Когда контрагент прогоняет такую пару через сверку имени с номером,
сверка падает, и он обязан удерживать **24 процента с каждого платежа** нам
до получения исправленной формы. В федеральной закупке расхождение имени
между W-9, SAM и счётом это ещё и повод придержать оплату.

Там же был адрес `North Miami Beach` вместо `Aventura`, должность
`Managing Member` вместо `Member` и устаревшая редакция бланка.

**Прежний файл не отправлять никому.**

### Куда W-9 нужен

* флоридский Substitute W-9 на `flvendor.myfloridacfo.com`, без него не
  открывается MyFloridaMarketPlace;
* кредитные заявки и открытие счетов у дистрибьюторов;
* по запросу заказчика при присуждении контракта.

### Что проверить прежде, чем отдавать

Классификация `S` в строке 3a верна только если по компании подавалась и
была принята форма 2553. Если подтверждения от налоговой нет, LLC с одним
участником по умолчанию disregarded entity, и галочка ставится другая.
Поменять значение `LLC_CLASS` в `tools/w9.py` и пересобрать.
