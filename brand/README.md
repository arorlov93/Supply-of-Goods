# Логотип ISP GROUP LLC

Собирается командой, шрифт ни на чьей машине не нужен: буквы превращены в
кривые.

```
python3.13 tools/logo.py        # SVG
python3.13 tools/logo-png.py    # PNG из них
```

---

## Идея знака

Шар это мир. Линия выходит за шар вправо и упирается в золотую точку. Это
путь товара из мира в конкретный адрес. Шар перекликается с точечным
глобусом на первом экране сайта, то есть знак и сайт говорят одно и то же.

## Цвета, те же, что на сайте

| Название | Код | Где |
|---|---|---|
| Чернила | `#0e2a26` | буквы и знак на светлом |
| Золото | `#b8862b` | точка назначения, всегда и везде |
| Кремовый | `#e8d9b4` | знак и слово GROUP на тёмном |
| Глубокая зелень | `#071c19` | фон иконки и тёмных плашек |
| Белый | `#ffffff` | слово ISP на тёмном |

Шрифт: **Schibsted Grotesk**, ISP начертанием 700, GROUP начертанием 400,
дескриптор 500 с большим межбуквенным просветом.

## Что брать в каком случае

| Файл | Куда |
|---|---|
| `logo-light.svg` | сайт на светлом фоне, документы, бланки |
| `logo-dark.svg` | тёмная шапка и подвал сайта |
| `logo-light-plain.svg` | везде, где высота меньше 32 пикселей: шапка сайта, подпись в письме. Без дескриптора, потому что мелкий текст превращается в грязь |
| `logo-dark-plain.svg` | то же на тёмном |
| `logo-stacked-*.svg` | вертикальный, для квадратных мест: аватар, визитка, печать на документе |
| `mark-ink.svg`, `mark-cream.svg` | только знак, без букв |
| `icon.svg`, `favicon-*.png` | иконка вкладки, ярлык на телефоне, аватар в соцсетях |
| `logo-email.png` | подпись в письме, 720 пикселей, вставлять шириной 360 |

PNG сделаны с прозрачным фоном, кроме `logo-email.png` и иконок.

## Правила

* **Не растягивать.** Только пропорционально.
* **Свободное поле** вокруг логотипа не меньше высоты буквы I.
* **Не перекрашивать.** Две версии, светлая и тёмная, больше не нужно.
* **Не ставить на пёструю фотографию.** Если очень надо, под логотип
  подложить плашку глубокой зелени.
* **Мельче 24 пикселей по высоте** использовать только `*-plain` или знак.

## Подпись в письме

Вставить картинку `logo-email.png` шириной 360 пикселей, под ней текст:

```
Aleksandr Orlov · Member
ISP GROUP LLC
16395 Biscayne Blvd, North Miami Beach, FL 33160
(929) 830-0038 · info@ispgroupgc.com · ispgroupgc.com
```

Готовый блок для Gmail лежит в `brand/signature.html`: открыть файл в
браузере, выделить всё, скопировать и вставить в настройки подписи Gmail.
